# 3D figures

Rigged, animated characters and objects on the web surface: a hero figure, a cast of NPCs, item art. Not in the template; add it per app. Distilled from Candidate Strike (2026-11). Mobile shows a pre-rendered image instead.

## Shape

```
web/src/<area>/
  three/SafeCanvas.tsx   error boundary around every <Canvas>, with a DOM fallback
  avatar/
    Scene.tsx            the Canvas: lights, stage, composer; default export, loaded with next/dynamic({ ssr: false, loading: <the DOM fallback> })
    Figure.tsx           one rigged character: clone, dress, measure anchors, animate
    gear.tsx props.tsx   accessories built from primitives at real size (metres)
    skins.ts             finishes: procedural canvas tiles (Dressing)
    Fallback.tsx         a figure built from primitives; shown under Suspense and by the inner boundary
    FigurePreview.tsx    one figure, for the dev route and icon capture
    avatar.config.ts     { src, height, rotationY, idleClip, draco }: swap in a real .glb without code changes
web/public/models/       .glb files; add "/models/(.*)" to PUBLIC_PATHS in proxy.ts
web/public/figures/      pre-rendered icons (.webp; Verification)
design/<area>/           sources, prompts, licence manifest, README (pipeline + credits)
```

Raw colours for 3D live in the area's theme file (`theme.ts`); doctor exempts paths containing `theme` or `tokens`.

## Loading

- Two boundaries, never a blank space or a 3D spinner:
  - outside: `SafeCanvas` (an error boundary around the `<Canvas>`) shows a DOM/CSS fallback when WebGL or the scene fails; the same fallback is the `next/dynamic` `loading`;
  - inside: `<ErrorBoundary fallback={<Fallback/>}><Suspense fallback={<Fallback/>}>` shows the primitive figure while a model loads or after it fails.
  - Never `fallback={null}`.
- `useGLTF(src)`, then `SkeletonUtils.clone(gltf.scene)` per instance. Never mutate the cached scene; clone each material before changing it.
- Fit to the configured height, never a constant: skinned bounds (below) → scale, feet on y 0, centred in x and z.
- No Draco: drei's decoder loads from gstatic.com, so `draco` stays false unless you self-host the decoder. Compress with meshopt (bundled). Preload only what the first view shows.
- A `<Canvas>` per list item is never acceptable. Lists and tiles use pre-rendered images (Verification).
- **The fallback figure** is real work, not a placeholder: tapered `LatheGeometry` limbs and torso, a procedural idle in `useFrame` (breathing by chest scale, a weight shift, a look-around, an arm pose per held item), held items following the hand's world position and staying upright.

## Characters as data

A cast is content, not components:
- `Look { body, skin, head?, face?, extra?, held?, model? }` per character; the kit is `look.model ?? BY_BODY[look.body]`.
- `Kit { src, cloth, parts, eyes }`: the file, the material that takes the finish, a RegExp of the parts it covers, the eye material.
- `HOLD: Record<Held, { carry: "front" | "side", depth, lift, turn }>` per held item (Accessories).
- `HeadFit` is a type (Accessories). The primitive figure carries a hand-measured one, so the same head gear fits both figures.

## GLTFLoader and skinned meshes

| Symptom | Cause | Do |
|---|---|---|
| Bone lookup fails | names are sanitised: `Wrist.R` → `WristR` | try both spellings (`getObjectByName(name.replace(".", ""))`) |
| Regex on mesh names misses parts | a part with several materials loads as a `Group` of meshes named `Part`, `Part_1`, …; the glTF node name sits in `userData.name` on the part | classify by `o.userData.name ?? o.parent?.userData.name` |
| Bounds or raycasts collapse to the origin | a cloned skeleton's bone matrices are empty until it renders | `scene.updateMatrixWorld(true)`, then `skeleton.update()` on every SkinnedMesh before measuring |
| Gear oversized or off-centre | a world AABB of a turned figure, converted back, is inflated | `skinnedMesh.computeBoundingBox()` (mesh space, skinned), then `applyMatrix4(inverse(root.matrixWorld) × mesh.matrixWorld)` |
| Everything looks like plastic | FBX2glTF kits arrive with metalness ≈0.4, roughness ≈0.4 | on load: metalness 0, roughness ≥ 0.8, `envMapIntensity` 0.8; eyes ≈ 0.45 |
| Bind-space axes surprise you | Blender exports through an armature rotation: attribute space is often Z-up with the front toward −Y | read the POSITION accessor `min`/`max` per primitive before writing shader maths |

## Dressing without UVs

- **Recolour** by `part:material` (`Body:Purple`; `*:Skin` for any part). The same material often paints several parts, e.g. hoodie and shoe uppers.
- **Prints and painted panels** go in bind space:
  - In `onBeforeCompile`, pass `position`/`normal` to varyings in the vertex shader. Bind-pose attributes keep the pattern fixed to the cloth while the skeleton moves.
  - In the fragment shader, after `#include <map_fragment>`, sample a texture triplanar, or `step()` out a panel (an open jacket, a tee).
  - Set `customProgramCacheKey`. Keep uniforms per material.
- **Finishes** (patterns on clothing) are procedural canvas tiles (`skins.ts`):
  - 256², cached per finish in a module `Map`, created only in the browser; `SRGBColorSpace`, `RepeatWrapping`, anisotropy 4.
  - Drawn with a seeded PRNG, so a finish looks the same on every visit. No seams: draw each shape at all nine ±tile offsets.
  - Applied as above, to the kit's `cloth` material on its `parts` only: base colour white so the tile shows true, weights `pow(abs(n), 4)` normalised, `diffuseColor.rgb *= finish`, tile scale `6 / bindHeight` so pattern size matches across models.
  - On primitives it is a plain `map`; clone the texture before setting `repeat` (the cached one is shared).
- **Replace a part** (a hat, glasses) by setting `mesh.visible = false` on its primitive, then adding your own geometry in a fitted frame. For new hair, keep the kit's own hair recoloured as a base under it: nothing you add then leaves the skull showing. If the kit already models a part you would add (a tie), detect its material and skip yours.

## Accessories

- **Measure the head, don't scale to it.** One stretched frame can't fit glasses, headphones and hats at once. Read the posed head's vertices (`mesh.getVertexPosition` applies skinning) into a fit in metres, with its origin between the eyes and as far back as the ears:
  - eye spacing, eye front, and the brows' front (lenses sit just ahead of the brows);
  - nose tip and its height, upper-lip front, chin;
  - half-width at the ears, of the skin and over the hair;
  - back of the head, skull top, hair top, and the hair's width, front and back above the eyes (for hats).

  Size every accessory from the feature it sits on, at real size:
  - glasses: end pieces out to the head's sides, temple arms back to the ears, hooks behind them;
  - headphones: a band from ear to ear over the hair (a superellipse follows a boxy head better than an ellipse), with cups clear of the hair;
  - hats: pulled down over the hair rather than perched on its top.

  Head gear renders only after the first frame has measured the head (set the fit from the first `useFrame`). Shades: `MeshPhysicalMaterial`, clearcoat 1.
- **Hair you build:** locks on a Fibonacci spiral (golden angle 2.39996 rad) over a superellipsoid shell (n ≈ 2.6) fitted to `HeadFit.hair`. Each lock is a flattened low-poly sphere with `flatShading`, oriented with `Matrix4.makeBasis(across, down, normal)`; cut lengths by facing direction, clamp the fringe, flick the ends out.
- **Chest:** raycast the body from the front at two heights (gives position and tilt). Chest gear may be authored once on a reference torso and scaled uniformly by the measured shoulder span ÷ the reference span.
- **Bind every frame to a bone.** Measure once, on the first frame, and store each frame bone-local: `inverse(bone.matrixWorld) × frameWorld`. Every frame, call `bone.updateWorldMatrix(true, false)` (or read last frame's pose), then compose `bone.matrixWorld × local` into the figure's space.
- **Held items need a hold, not an offset.** A kit's idle hangs the hands with the fingers straight, so nothing can sit in them upright. Add a pose layer in `useFrame`, after the mixer (drei's `useAnimations` registers first):
  - turn the forearm to point ahead (`setFromUnitVectors` on its world direction, converted to the bone's local rotation);
  - close each finger joint about `fingerDirection × palmNormal`. Get the palm normal from `(index − pinky) × (knuckle − wrist)`, negated for the mirrored hand.
  - Post-multiply rotations onto the bone's own; for a bone the clip doesn't animate, bend from the rest you saved, or it accumulates.
  - Blend the layer out (`1 − action.getEffectiveWeight()`) while a clip such as a wave uses that arm.

  Place items at the knuckles plus the palm normal × the item's radius. Cups, cans and screens stay upright (position only), with screens turned to the viewer. Carried laptops hang fixed in the hand. Dark items against dark clothes disappear; check them.
- **Necklaces** are a tube along a U lying on the chest (`TubeGeometry` + `CatmullRomCurve3`). A torus ring around the neck shows as a dash.

## Stage and render recipe

- **Lights:**
  - `hemisphereLight` (cool sky, warm ground, 0.6), a warm key directional and one or two cool rim lights;
  - `<Environment frames={1}>` built from `Lightformer`s. Drei presets download HDRs from a CDN.
- **Composer:** `<EffectComposer multisampling={0}>` with N8AO (`halfRes`, `quality="performance"`), Bloom (`mipmapBlur`, threshold 1, intensity 0.2), `ToneMapping` (NEUTRAL, which keeps saturated colours) and SMAA.
  - The composer switches off `gl.toneMapping`, so set tone mapping only as the effect.
  - Canvas alpha survives. Check the figure over the real page backdrop.
- **Canvas:** `dpr={[1, 1.5]}`; `ContactShadows` for animated figures (AccumulativeShadows suits static scenes only).
- **Camera** for a standing figure: fov 30 at `[0, 1.15, 4.7]`, `lookAt` chest height in `onCreated`. Environment `resolution={128}`; N8AO `aoRadius 0.5, distanceFalloff 1, intensity 2`.
- **Metals:** metalness 1 renders near-black without a bright environment. About 0.6 under the figure stage; 0.75–0.9 where four Lightformers light the object (Objects).
- **Glows:**
  - Anything meant to glow uses a colour above 1 (`new Color(c).multiplyScalar(4)`, `toneMapped={false}`) so Bloom picks it up.
  - Auras are a fresnel `ShaderMaterial` (`AdditiveBlending`, `depthWrite: false`, rim `pow(1 − |n·v|, 2.2)`, colour × 2.5, brightness pulsed through a uniform), never a translucent sphere over the face.
- **Turntable:** drag with pointer capture on `gl.domElement`; inertia `velocity *= 0.04 ** dt`; damp back to the rest angle unless inspecting; `touch-action: pan-y` on the canvas keeps the page scrolling. Wheel zoom only while inspecting (`passive: false`, clamped), raising the camera and its target as it closes in. Entrance: a −1.75π spin and a 0.35 m rise over 1.8 s.

## Objects

A box, case or device on its own stage:
- **Recipe:** no composer; the renderer's `ACESFilmicToneMapping`, exposure 1.1, `dpr={[1, 2]}`, `Environment` (resolution 256) from four Lightformers.
- **Trays and frames:** `ExtrudeGeometry` of a rounded-rect `Shape` with a rounded-rect hole, bevelled. **Hinges:** an outer group on the hinge line, an inner group offset back by the lid's depth; rotate the outer (`easeOutBack` gives the overshoot).
- **Canvas textures** (labels, prints, screens): paint after `document.fonts.load(…)` with the families next/font puts in CSS variables; anisotropy `gl.capabilities.getMaxAnisotropy()`; cancel and `dispose` on unmount; change the material's `key` when the map arrives so it recompiles. Grain through `getImageData`, soft edges with `destination-in` compositing; seed anything that must look the same twice. Screens are `toneMapped={false}`.
- **Printed surfaces:** `meshPhysicalMaterial`, clearcoat ≈ 0.6. A sheen is an additive plane whose `map.offset.x` scrolls.
- **Light out of an opening:** additive glow and ray planes (`toneMapped={false}`, `depthWrite={false}`) and a `pointLight` ramped up with them.
- **Idle life:** pointer parallax from `state.pointer`, a slow sway and bob, hover scale 1.05; R3F pointer events on the group for hover and press. The opening plays from the shared beat sheet (scenes.md), never from its own timers.

## Animation

Sequences that span the scene, the page and sound (an opening, a reveal) follow scenes.md.

- `useAnimations(gltf.animations, ref)` loops Idle. A one-shot intro (Wave) plays with `LoopOnce` and `clampWhenFinished`, then crossfades back to Idle about 0.4 s before it ends.
- **Reduced motion:** Idle at `timeScale 0` (a still pose), and no turntable sway or entrance spin.
- **Clips bind by bone name.** Common skeletons:

  | Rig | Bone names |
  |---|---|
  | Quaternius modular kits | `Hips`, `Chest`, `Neck`, `Head`, `UpperArm.L`, `Wrist.R` |
  | UBC / Universal Animation Library | UE5 style: `pelvis`, `spine_01–03`, `neck_01`, `Head`, `hand_r` |
  | Mixamo | `mixamorig:Hips` (loads as `mixamorigHips`) |

  Share one skeleton across characters, or retarget once offline with `SkeletonUtils.retargetClip(target, source, clip, { names: { targetBone: "sourceBone" }, hip })` and ship the result.

## Generated characters

1. **Reference images** from an image model (`gpt-image-2` edits, given photos).
   - Full body, orthographic front view, A-pose with arms about 35° out, hands open and empty.
   - Plain flat background; no floor, shadow, props, logos or text.
   - Generate back and side views from the front image, so they stay consistent.
   - Props are separate meshes.
2. **Mesh:** the Hugging Face Space `microsoft/TRELLIS.2` via `gradio_client` (Python ≥ 3.10): `/start_session`, `/preprocess_image`, `/image_to_3d` (resolution 1024), `/extract_glb` (minimum 100k faces). Decimate to about 25k yourself and convert its textures to PNG (WebP comes last, at ship time).
3. **Rig:** the Space `jasongzy/Make-It-Animatable-v2`, `/pipeline`, with rest pose A-pose. It produces a Mixamo skeleton and bakes one clip per call (Breathing Idle, Waving, Drinking, Holding Idle).
4. **Ship** through `avatar.config.ts` after `resize`, `webp`, `meshopt`. Parent held props to `mixamorigRightHand` / `mixamorigLeftHand`.

**Quotas and costs:**
- ZeroGPU needs a Hugging Face token. Anonymous callers get about one GPU run a day; a free account 5 minutes a day; PRO 40 minutes.
- Paid, with rigging and animation: Tripo (about $1 per character with 4 clips) or Meshy Pro ($20 a month covers about 20).
- Hunyuan3D's licence excludes the EU, UK and South Korea.

**API keys** live in a git-ignored env file. Scripts load them (`--env design/<area>/.env`) and redact them in errors. An agent never reads, prints or inspects a key; it runs the script.

## Verification

- **A dev-only route** shows one figure: `app/(site)/dev/figures/page.tsx`, `?c=<id>`, calling `notFound()` in production. It shows a still pose unless `&motion=1` (idle) or `&reveal=1` (the entrance); `&yaw=<radians>` turns the figure, `&icon=1` uses the icon framing. Hair and hats need side and back views, and holds need the animated wave.
- **Headless Chromium** (puppeteer-core):
  - Flags: `--use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist`.
  - Screenshot at `deviceScaleFactor: 2`, crop with macOS `sips --cropToHeightWidth h w --cropOffset y x`, then lay the crops out as a contact sheet and look at it.
  - SwiftShader is slow: wait for network idle plus a few seconds, and never judge motion timing from it.
  - Capture `pageerror` and console errors for every shot. A hydration diff names the element that differs.
- **Measure in Node first.** `GLTFLoader.parse` works headless for untextured models: pose a clip with an `AnimationMixer`, call `skeleton.update()`, and print bone and vertex positions. That gives hand and face dimensions before you write any fitting code.
- **Check:** every figure with every accessory; the real page over its backdrop; 375 px and desktop; reduced motion.
- **Item icons** for tiles and lists:
  - Add an icon mode to the scene: a fixed three-quarter camera, no platform, `preserveDrawingBuffer`, 480 × 300 at `dpr 1`. The composer keeps alpha, so the WebP is transparent.
  - The page publishes `window.__figureFrames` (counted in `useFrame`) and `window.__figureIcon()` (returns `canvas.toDataURL("image/webp", 0.9)`).
  - A script (`figure:icons`, puppeteer-core) opens `/dev/figures?c=<id>&icon=1` for each id, waits for network idle and then until 12 more frames have drawn (never a fixed delay), and writes `web/public/figures/<id>.webp`. Chrome comes from `--chrome`, `CHROME_PATH`, the installed app, then Playwright's Chromium; pass `--disk-cache-size=1`. `--only <id,id>` limits the run; otherwise the ids come from `window.__figureIds`, which the dev page publishes.
  - Tiles show them with `<img loading="lazy" decoding="async">`. Re-run the script whenever a model or its dressing changes.
